# AI for Envinronmental Data Science 
## Workshop 1: Intro to LLMs & Prompting Fundamentals

This repository contains materials for the workshop on *Intro to large language models (LLMs) and prompting fundamentals* for the [Masters in Environmental Data Science (MEDS)](https://bren.ucsb.edu/masters-programs/master-environmental-data-science/academics-meds-program), at the Bren School of Environmental Science & Management at UC Santa Barbara.

For more information visit the [MEDS AI for Environmental Data Science Workshop Series website](https://ucsb-meds.github.io/AI-for-EDS/).


## How to run this demo

The demo can be run using Binder, which allows you to run Jupyter notebooks in the cloud without needing to install anything locally. 

Click on the icon below to run the notebooks:

[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/carmengg/code-for-genai-demo/HEAD)

The demo is designed to be facilitated in a workshop setting, where an instructor uses the `key.ipynb` notebook to guide participants through the exercises while participants follow along in the `demo.ipynb` notebook.

## About the data

This demo uses the [Bootstrap Sea Ice Concentrations from Nimbus-7 SMMR and DMSP SSM/I-SSMIS, Version 4](https://nsidc.org/data/nsidc-0079/versions/4#anchor-documentation) data from the National Snow and Ice Data Center (NSIDC). The [user guide](https://nsidc.org/sites/default/files/documents/user-guide/nsidc-0079-v004-userguide.pdf) is available through the dataset's main page and also included in the `aux_files` folder.

There are three folders with data in this repository:
- `monthly_data_2024/`: monthly sea ice concentration data for the year 2024, as downloaded from NSIDC.
- `monthly_data_2021/`: monthly sea ice concentration data for the year 2021. One of the files has been updated to produce an error in the code for educational purposes.
- `aux_files/monthly_data_2021_raw/`: monthly sea ice concentration data for the year 2021, as donwnloaded from NSIDC.

The data was donwloaded using a Python script generated by the [NSIDC Data Search Tool for this dataset](https://nsidc.org/data/data-access-tool/NSIDC-0079/versions/4) available in the `aux_files` folder.
